# ЧебурNET Traffic Control 1.0.0

Первый стабильный релиз самостоятельного менеджера фильтрации входящего трафика Linux.

- IPv4/IPv6 и три внешних списка: antiscanner, government_networks, skipa.
- Одно действие для включения фильтрации, автозапуска и ежедневного обновления.
- Ручные блокировки IP/CIDR и исключения администратора и панели.
- Русское меню, отчёт о компонентах, топ IP и организаций, журналы и самодиагностика.
- Короткая команда `ctc`, проверка пакетов и подтверждение перед установкой.
- Собственная таблица nftables и восстановление локальных правил после перезагрузки.

После установки выберите «Включить фильтрацию» или `ctc on`. Отдельного шага подтверждения включения нет.
Для уже установленного компонента используйте [обновление](UPDATE.md), сохранив конфигурацию и исключения.

Проверены модульные тесты, сценарии включения и ошибок применения/записи/служб, адаптивное оформление,
синтаксис Python и SHA-256. CI использует Python 3.10 и 3.12. На Ubuntu 24.04.4 ранее подтверждены установка,
таблица, таймер и восстановление после перезагрузки. Новое включение одним действием на пользовательской
VPS ещё требует проверки после обновления. Проверка наличия таблицы не заменяет сетевой тест блокировки.

SSH-порты и исключения пропускаются раньше блокировок. Охватывается INPUT, включая Docker host;
Docker bridge и исходящий трафик не входят в область фильтрации.
