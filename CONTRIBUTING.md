# Участие в разработке

Предлагайте изменения через Issue или Pull Request. Укажите проблему, результирующее поведение
и выполненные проверки. Пользовательские сообщения пишите на русском.

Используйте стандартную библиотеку Python 3.10+. Сохраняйте изоляцию таблицы `inet cheburnet_tc`,
приоритет SSH и исключений, совместимость конфигурации и блокировку параллельных операций.
Изменения правил, состояния и служб сопровождайте тестами на сбои.

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile cheburnet-traffic-control.py
sha256sum cheburnet-traffic-control.py > SHA256SUMS
sha256sum -c SHA256SUMS
```

Изменения сетевой логики проверяйте в отдельной VM с консолью: IPv4/IPv6, исключения, перезагрузка
и сочетание с UFW. Для интерфейса проверьте узкий терминал, `NO_COLOR` и вывод в файл.
Сохраняйте уведомление MIT и авторство сторонних компонентов.
